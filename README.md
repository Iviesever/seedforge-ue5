# SeedForge

SeedForge is a deterministic asynchronous dungeon-generation lab for Unreal Engine 5.8. The repository is being built as an AI-assisted, evidence-first C++ portfolio project.

The initial delivery contract and implementation plan live under `tasks/20260903-113501-ue58-agentic-sprint/`.

## Current status

The UE project and runtime plugin scaffold are present. Build, test, graybox, packaging, and portfolio evidence are validated incrementally and are not claimed complete until their recorded gates pass.
